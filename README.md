# 📊 Interactive YouTube Data Analytics Pipeline

An end-to-end data visualization pipeline built on macOS to parse, clean, and visualize YouTube channel performance metrics dynamically.

## 🚀 Key Features
* **Interactive Engagement Matrix:** Plots Views vs. Likes using a scatter layout where data points show video details on hover.
* **Automated Data Cleaning:** Built-in validation structures that automatically filter out summary rows (like "Total") and dynamically handle missing metrics.
* **Responsive Architecture:** Leverages web-rendering engines to allow zoom, filter, and dynamic scaling inside any web browser.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Data Processing:** Pandas
* **Visualization:** Plotly Express
